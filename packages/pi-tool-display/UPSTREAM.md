## Update procedure

1. Verify the selected upstream tag, commit, license, and notices directly from MasuRii/pi-tool-display.
2. Stream the selected GitHub source archive directly into a fresh package directory. Do not copy a temporary clone or generated output.
3. Restore this package's peer range, local provenance records, and monorepo installation guidance.
4. Run upstream tests and Pi 0.85.x compatibility tests against a clean local Pi build.
5. Run the combined visual trial with `pi-visual-profile` before changing the compatibility claim.
